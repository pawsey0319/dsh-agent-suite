# 任务雷达（dsh-task-radar）

> DSH 统一 Agent 控制台 · P0/P1。对应需求 R3（见仓库 `docs/PRD.md`）。
> 实现细节与工程纪律见仓库 `docs/DEV.md`（§4 原生 HUD）。

## 它解决什么

DSH 里同时跑多个任务时，你得来回切会话才知道谁在跑、谁在等你。
任务雷达把这件事折叠成**桌面上一个小圆圈**：有任务在跑就显示数字，有任务等你批准就整圈变红脉冲，
鼠标移上去展开任务列表，双击回到 DSH。

它不依附 DSH 窗口——常驻在所有 Space 与全屏应用之上，可以拖到桌面任意位置并记住位置。

## 怎么用

1. 装好后桌面右下角出现一个 **56 pt 小圆圈**（默认位置；拖到别处会被记住）。
2. 圆圈里的大数字 = **正在运行的顶层会话数**（子 agent 不计入）。
3. **鼠标移上去**：0.18s 展开成 320 pt 宽的任务面板，列出运行中的会话（agent 徽标 + 任务标题），
   超过 6 条显示「还有 N 条」；副行显示「需批准」与「完成未看」。
4. **移开鼠标**约 250ms 后缩回圆圈（移进面板内部不会收起）。
5. **双击圆圈**回到 DeepSeek Harness；**单击圆圈空白处什么都不做**（只当拖动起点，避免误触）。
5.1 外部 agent（Codex 等经 Agent Bridge 跑的任务）**完成后会以灰行出现在列表里**，副行写
   「完成未看 · 点击看结果」——点这一行会**置为已读并打开结果详情**；点面板里的
   「完成未看 N」那一行等于**全部置为已读**。
5.2 **结果详情**：点完成行后面板切换成「任务结果」——agent 徽标、任务标题、一行
   `耗时 4.5s · 88936 tokens · 44 事件`、以及最终回答正文（最多 6 行，超出截断）。
   点面板任意位置返回列表。
5.3 **完整事件流**：摘要页底部点「事件流 N 条 ›」进入二级视图——逐行 `#序号 类型 内容`
   （TEXT / REASONING / ITEM.START / TURN.END / USAGE…，MCP 启动之类的原始通知已过滤），
   右上角显示 `1-12/98`，**滚轮翻页**；点底部「‹ 返回结果」回到摘要。
   事件流页点空白不会关闭（避免误关）。
5.4 **运行中的外部任务也能点开**：列表里跑着的 Codex run 点一下就是「实时详情」——
   正文随它输出而更新，事件流右上角挂绿点「● 直播中」，每 1.5 秒增量追加；
   你停在底部时自动跟到最新，向上翻看时不会把你拽回来；跑完自动停止并补齐最终正文。
5.5 **看单条事件的原始数据**：事件流里点**任意一行**，进入「原始事件」页——
   等宽展示那条 Codex 通知的原始 JSON，可滚轮翻页，底部「‹ 返回事件流」回去。
5.6 **运行中的 DSH 会话行可以点**：点一下就跳回那条会话（HUD 先把 DSH 拉到前台，
   页面侧 1.2 秒内切到对应会话）。超过 15 秒没被消费的跳转请求自动作废。
5.7 **有任务等你批准**时，待批准行排在最前面（橙色徽标 + 「待批准 · 点击处理」）。
    点开是「任务审批」页：标题显示**真实发起方 + 具体命令**（`CODEX 请求批准` / `CLAUDE 请求批准`，
    正文就是那条命令），底部「✕ 拒绝 / ✓ 批准」直接把决定回传——不用切回会话。
5.8 **Claude Code 任务与 Codex 任务在同一张面板里**（2026-11-16 起）：两者的运行中/完成态、
    事件流、原始 payload 完全同构，行尾的 agent 徽标会写 `CODEX` 或 `CLAUDE`。
    Claude 的**只读工具**（读文件/搜索/列目录/看时间线）直接执行不打扰你，凡是 `Bash/Write/Edit`
    这类有副作用的都要在这里点「批准」；25 秒没人处理会自动拒绝。
   点开是「任务审批」页：一句话说明它想干什么，底部「✕ 拒绝」「✓ 批准」，点了立刻生效；
   5 分钟内不处理，桥侧会自动拒绝。
6. **有任务等你批准**时：整圈变红并轻微脉冲，圆点转红呼吸。处理完自动恢复。
7. 右键菜单：刷新 / 置顶开/关 / 隐藏 5 分钟 / 退出。

## 数据从哪来

`GET /x-radar/radar`（本插件 Host 半提供，每次 DSH 启动写 `~/.dsh/agent-bridge/radar-url.json` 让 HUD 跟随端口）：

- 圆上能直接读到的信息（2026-11-16 起，尺寸仍是 56pt）：圆内数字=正在处理的父会话数；
  外环分段=每个活跃任务一段（蓝=运行中、橙=等你批准、绿=完成未看）；内圈细弧=团队的成员完成比例；
  圆底小排点=团队成员（绿=进行中、亮灰=已完成、暗灰=待处理）。
- 团队判定：`agentTeam.enabled` 为真，**或** `subagentCatalog` 里有 `agent-teams:` 前缀的成员
  （临时用 subagent 起队的会话也算团队）。
- `counts.running`：顶层运行中会话数（`parentSession` 子会话被过滤，3 个子 agent 并发仍显示 1）
- `counts.approvals`：需批准数（含 Agent Bridge 外部 run 的 `needs-approval`）
- `counts.doneUnread`：完成未看数
- `items[]`：`{id, kind, status, title, agent, updatedAt}`，排序 `needs-approval > done > running`

## 边界（已知限制）

5.9 **胶囊只显示父会话；只有 Agent Team 才展开成员**（2026-11-16 起）：普通会话调用的子 agent 不进胶囊、
   也不出现在任何明细里——点父会话直接跳回 DSH 那条会话。只有 `agentTeam.enabled` 的团队会话，父会话行才
   显示「团队 N 名成员 · 点击看进度」；点开是成员页，每行「任务/角色 + 进行中/空闲 + 任务状态（待处理/进行中/
   已完成）+ token」，点某个成员跳回它自己的会话。截图 `docs/assets/hud-children.png`。
- 审批在 HUD 内完成（规则 2.13/2.16）：Codex 的 server request 与 Claude 的 PreToolUse 闸门都进同一队列；
  Claude 侧 25 秒无人处理自动拒绝（hook 超时），Codex 侧 5 分钟。
- 「完成未看」的行**不能跳转**到 DSH 页面：它们是没有 DSH 会话的外部 run，点它是「置读 + 看结果」。
- 事件流对运行中的任务走**1.5s 增量轮询**（`?since=`），不是 SSE；任务结束后停止轮询。
- 原始事件页展示的是桥梁落盘的 `raw`：Codex 是通知的 params，Claude 是 stream-json 的**整行事件**（形状不同，但都在同一页看）。
- 事件流的 `reasoning` 行只显示模型吐出的推理摘要（多为英文思考片段），不是完整思维链。
- 双击只负责把 DSH 激活，暂不支持「双击定位到某条会话」（`uiWorkspace.openSession` 在 Host 侧，需再加 IPC）。
- 位置按屏幕坐标保存；换显示器/改分辨率后可能落在负坐标区，HUD 会夹回最近屏幕。
- 需要 macOS 14+（依赖 Swift/AppKit + `CGWindowList` 验证工具）。
